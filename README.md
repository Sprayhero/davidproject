# 思源学校学生成长档案小程序

基于图片设计稿开发的微信小程序，用于展示学生的成长档案信息。

## 项目结构

```
├── pages/
│   └── index/              # 主页面
│       ├── index.wxml      # 页面结构
│       ├── index.wxss      # 页面样式
│       ├── index.js        # 页面逻辑
│       └── index.json      # 页面配置
├── images/                 # 图片资源目录（需要添加）
├── app.js                  # 小程序入口文件
├── app.json                # 全局配置
├── app.wxss                # 全局样式
├── project.config.json     # 项目配置
└── sitemap.json           # 站点地图配置
```

## 功能特性

### 主要界面
- ✅ 绿色渐变背景设计
- ✅ 学校Logo和标题展示
- ✅ 学生信息卡片（头像、姓名、班级）
- ✅ 成长数据展示（成长值、励章等级）
- ✅ 功能模块网格布局
- ✅ 底部导航栏

### 功能模块
1. **行为基础** - 学生行为表现记录
2. **学业基础** - 学习成绩和表现
3. **实践活动** - 各类实践活动参与情况
4. **体质健康** - 身体健康和体育成绩
5. **兴趣爱好** - 个人兴趣和特长展示
6. **艺术素养** - 艺术类活动和作品
7. **个性发展** - 个性特点和发展轨迹

## 样式设计

### 色彩方案
- 主色调：绿色渐变 (#4ecdc4 → #44a08d)
- 卡片背景：半透明白色毛玻璃效果
- 模块图标：多彩渐变背景
- 文字：白色/深灰色

### 交互效果
- 按压反馈动画
- 毛玻璃背景效果
- 渐变色彩搭配
- 圆角卡片设计

## 使用说明

1. **开发环境**
   - 微信开发者工具
   - 小程序基础库 2.19.4+

2. **图片资源**
   需要在 `images/` 目录下添加以下图片：
   ```
   ├── images/
   │   ├── school-icon.png      # 学校图标
   │   ├── search-icon.png      # 搜索图标
   │   ├── avatar.png           # 学生头像
   │   ├── trophy.png           # 奖杯图标
   │   ├── brain-icon.png       # 行为基础图标
   │   ├── academic-icon.png    # 学业基础图标
   │   ├── flag-icon.png        # 实践活动图标
   │   ├── health-icon.png      # 体质健康图标
   │   ├── interest-icon.png    # 兴趣爱好图标
   │   ├── art-icon.png         # 艺术素养图标
   │   ├── personal-icon.png    # 个性发展图标
   │   ├── home.png             # 首页图标
   │   ├── home-active.png      # 首页激活图标
   │   ├── chat.png             # 聊天图标
   │   ├── planet.png           # 星球图标
   │   └── profile.png          # 个人图标
   ```

3. **部署步骤**
   - 用微信开发者工具打开项目
   - 修改 `project.config.json` 中的 `appid`
   - 添加所需的图片资源
   - 预览或上传小程序
